## The pitch

A sock drawer that holds a weekly tribunal where single socks testify about
their missing partners, then sentences the washing machine to community
service.

## How it works

`main.ts` (Node 22+) writes that single sentence to `/output/entry.txt`.
It checks the gate itself first: the text must be 1–220 characters and
exactly one sentence.

```sh
node main.ts
cat /output/entry.txt
```
